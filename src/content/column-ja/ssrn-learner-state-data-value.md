## 生成データの価値は決まっているのか

ニューラルネットの分類器は、実際のタスクのデータに加えて、LLM が生成したテキストや拡張したデータ、教師モデルから蒸留したソフトラベルといった補助データでも学習されるようになっています。補助データを足すかどうかを決めるとき、多くの研究はデータに付けた「価値」を手がかりにします。生成データの多様性、実データへの忠実さ、Shapley 値や影響関数による事例ごとの寄与などです。これらは主にデータの側の性質として価値を扱っています。

感情認識は、この前提を確かめるのに向いたタスクです。LLM はラベル付きの感情テキストをほぼコストなしで作れます。一方で感情のラベルは主観的で、同じ文でもアノテータの判断が割れます。分類器が目指すべき答えは、人間の判断の分布というソフトな分布になります。

この研究の問いは、**感情認識における補助データの価値は、データに固定された性質なのか、それともデータ・学習者の状態・評価指標の関係なのか**です。

## 分析の枠組み

<figure>
  <img src="/column-images/ssrn-learner-state-data-value/overview-1600.webp" alt="Overview of the analysis" />
  <figcaption><strong>Figure 1.</strong> 分析の流れ（論文の Figure 1）。入力は人間のラベル分布つきの実データ、補助テキスト、実データ n 件で学習した学生モデルです。(a)〜(d) の 4 段階で、価値 V(Q | P, θ<sub>n</sub>, L) の各条件を順に変えます。</figcaption>
</figure>

中心になるのは**実データ交換レート** f(n) です。実データ n 件で学習した学生モデルと、同じ n 件に補助データ m 件を足して学習した学生モデルを、同じ設定・同じシードで比べます。評価は人間のラベル分布に対する交差エントロピー（温度スケーリングで較正したもの）です。その差を「実データを m 件追加したら下がるはずのリスク」で割ります。f(n) = 0.5 なら、補助データ m 件は実データ 0.5m 件分の価値があり、負なら補助データがリスクを上げた、という意味です。

分析は 4 段階です。

1. **学習者の状態を変える**：実データ量 n を 500 から全件まで変え、同じ補助データの f(n) を学習曲線に沿って測ります。
2. **ラベルの向きを変える**：補助テキストと argmax ラベルを固定し、平均エントロピーもそろえたまま、ソフトラベルの確率質量をどこへ向けるかだけを変えます。
3. **テキストの出どころを変える**：同じラベルの向きを、生成テキストと取り置いた実テキストの両方に当てます。
4. **価値を予測できるか調べる**：混ぜて学習する前に計算できる量で、測った価値の順位を当てられるかを確かめます。

<figure>
  <img src="/column-images/ssrn-learner-state-data-value/directions-1600.webp" alt="Four label directions" />
  <figcaption><strong>Figure 2.</strong> 4 つのラベルの向き（論文の Figure 2）。黒が元のラベル y の質量、灰色が動かした質量です。teacher は実データで学習した教師モデルの確率、uniform は一様（ラベルスムージングに相当）、prior は実データのクラス事前分布、permuted は教師の確率のクラスを入れ替えたものです。どれも平均エントロピー H は同じにそろえています。</figcaption>
</figure>

2 段階目の対照として、**学生と同じ実データ n 件だけで学習した教師**も使います。全件で学習した教師では、教師の方向が効いても「教師が知っている追加の実データが蒸留されただけ」という説明が残るためです。

## 実験 1：同じデータの価値は実データ量で変わるか

<p class="experiment-label">Experiment 1</p>

<div class="setup">

**Setup**

- データ：GoEmotions（英語の Reddit コメント、28 クラス、1 文あたり約 3.4 人の判断の平均を目標分布とする）、WRIME（日本語の SNS 投稿、読み手 3 人の判断、K = 9）
- 補助データ：GoEmotions は Llama-3.1-8B-Instruct による 3 種の生成（ラベル条件付き生成、AugGPT、CoTAM）と、種文を編集する 5 種（EDA、AEDA、逆翻訳、LLM 言い換え、埋め込みによるオーバーサンプリング）。WRIME は Qwen2.5-7B-Instruct が生成した投稿と、取り置いた実投稿 4,500 件。各プール m = 4,500
- 学生モデル：GoEmotions は RoBERTa-base（3 シード）と DeBERTa-v3-base（1 シード）、WRIME は BERT-base Japanese v3（3 シード）
- 実データ量：n ∈ {500, 1k, 2k, 4k, 8k, 16k, 全件}。後半段階は 8k・16k・全件の 3 点

</div>

<figure>
  <img src="/column-images/ssrn-learner-state-data-value/exchange-curve-1600.webp" alt="Exchange rate across real-data sizes" />
  <figcaption><strong>Figure 3.</strong> GoEmotions・RoBERTa-base で、ラベル条件付き生成データ（one-hot ラベル）の交換レート。論文本文に書かれた 4 点を示しています。リスクの差がゼロをまたぐ点 n<sub>0</sub> は約 6,700 件です。</figcaption>
</figure>

同じ生成データの交換レートは、実データ量によって符号まで変わりました。n = 500 で 0.00、4k で 0.23 だったものが、16k で −0.75、全件で −0.71 になりました。AugGPT と CoTAM も、上がってからゼロをまたぎ、LLM による 3 つの生成法では 4 回の実行すべてで f(500) > f(全件) でした。

<figure>
  <img src="/column-images/ssrn-learner-state-data-value/pool-rates-1600.webp" alt="Late-stage exchange rates of different pools" />
  <figcaption><strong>Figure 4.</strong> 後半段階での交換レート。左は GoEmotions の全件での値、右は WRIME の後半段階の平均です。生成テキストに one-hot ラベルを付けると負になり、教師のソフトラベルや実テキストでは正のままです。</figcaption>
</figure>

ラベルの付け方でもこの曲線は変わりました。全件で学習した教師に同じ生成テキストを argmax で付け直しても、全件での値は −0.51 でした。教師の確率をそのままソフトラベルにすると、どの n でも正で、全件で 0.31 でした。実テキストに小さな編集を加える逆翻訳は全件でも 0.57 です。WRIME でも、生成テキスト（one-hot）は 8k まではほぼゼロで、その後下がって後半段階で −0.65 になりました。実テキストは読み手ラベルで +0.67、書き手ラベルで +0.70 でした。

符号は推定の仕方に依存しませんでした。微分を使わない別の換算 f<sub>eq</sub> と符号が一致したのは、打ち切りのないセルのうち GoEmotions で 256 件中 256 件、WRIME で 76 件中 76 件です。一方でゼロ点は学生モデルに依存し、DeBERTa-v3-base ではラベル条件付き生成のゼロ点が約 14,700 件と、RoBERTa-base よりかなり後ろでした。

## 実験 2：ソフトラベルの「向き」だけを変える

<p class="experiment-label">Experiment 2</p>

テキスト、argmax ラベル、平均エントロピーを固定し、ソフトラベルの向きだけを変えました。混ぜる量 a は 0.25 と 0.5 の 2 水準です。

<figure>
  <img src="/column-images/ssrn-learner-state-data-value/direction-1600.webp" alt="Entropy-matched direction intervention" />
  <figcaption><strong>Figure 5.</strong> エントロピーをそろえたラベルの向きの効果（論文の Table 2）。左は WRIME の後半段階の交換レート（3 シード平均、高いほど良い）、右は GoEmotions の後半段階の較正済み交差エントロピーの変化（a = 0.5、低いほど良い）を 2 シード分示しています。帯と点線は one-hot ラベルの値です。</figcaption>
</figure>

GoEmotions では、a = 0.5 の教師方向が 2 シードとも後半段階の交差エントロピーを下げ（−0.0213 と −0.0176）、one-hot ラベルは上げました（+0.0174 と +0.0219）。uniform は害の大部分を残し、permuted は one-hot よりも悪くなりました。WRIME では、a = 0.5 の教師方向が +0.20 で、uniform・prior・permuted は −0.55 から −0.93 でした。a = 0.25 では教師方向でも −0.07 で、害は減っても消えていません。向きと、動かす質量の量の両方が効いています。

この効果が蒸留で説明できるかを、学生と同じ実データだけで学習した教師で確かめました。

<figure>
  <img src="/column-images/ssrn-learner-state-data-value/same-teacher-1600.webp" alt="Same-data teacher on WRIME" />
  <figcaption><strong>Figure 6.</strong> WRIME で、教師を学生と同じ実データ n 件だけで学習したときの生成テキストの交換レート（論文の Table 3）。</figcaption>
</figure>

n = 8k で教師方向は +0.48 で、全件の教師を使ったときの +0.47 とほぼ同じでした。uniform と permuted は −0.24 と −0.18 です。教師が学生より多くの実データを知っているから効く、という説明ではこの結果を説明できません。ただし全件では教師方向も +0.02 にとどまり、ほかのプールはすべて −1.1 を下回りました。教師方向は a = 0.5 で害を消しましたが、どの n でも生成データを役立つものに変えたわけではありません。

## 実験 3：生成テキストと実テキストで、間違ったラベルの損失は同じか

<p class="experiment-label">Experiment 3</p>

テキストの出どころ（生成・実）とラベルの向き（teacher・permuted）を 2×2 で組み、permuted にしたときの交換レートの低下を「間違った向きのコスト」として比べました。生成テキストのコストを Δ<sub>gen</sub>、実テキストのコストを Δ<sub>real</sub> と書きます。

WRIME では Δ<sub>gen</sub> = −0.97、Δ<sub>real</sub> = −0.37 で、permuted ラベルの実テキストも +0.38 と正のままでした。GoEmotions では Δ<sub>gen</sub> = −1.07、Δ<sub>real</sub> = −0.88 で、permuted ラベルの実テキストは −0.29 と負でした。Δ<sub>gen</sub> < Δ<sub>real</sub> は両コーパスの 3 シードすべてで成り立っています。実テキストは間違った向きの損失を小さくしますが、いつも守ってくれるわけではありません。

ただし、エントロピーをそろえても、教師ラベルから permuted ラベルまでの距離は出どころごとに違います。WRIME では平均の全変動距離（TV）が生成テキストで 0.31〜0.32、実テキストで 0.26〜0.27 でした。そこで生成テキスト側の摂動を弱め、TV または KL ダイバージェンスを実テキストにそろえて測り直しました。

<figure>
  <img src="/column-images/ssrn-learner-state-data-value/matched-cost-1600.webp" alt="Strength-matched cost of the permuted direction" />
  <figcaption><strong>Figure 7.</strong> 摂動の強さをそろえたときの、permuted 方向のコスト（論文の Table 6）。括弧内は Δ<sub>gen</sub> < Δ<sub>real</sub> となったシードの数です。</figcaption>
</figure>

WRIME では TV をそろえると Δ<sub>gen</sub> は −0.97 から −0.73 になりましたが、まだ Δ<sub>real</sub> の約 2 倍です。強さの違いで説明できたのは差の約 40% でした。GoEmotions は差がもともと小さく、シード平均では向きが保たれたものの、TV をそろえた条件では 3 シード中 1 シードが −0.88 対 −0.89 でした。つまり、生成テキストで損失が大きいという結果は、WRIME でははっきり、GoEmotions では弱く残りました。

## 実験 4：学習前に価値を予測できるか

<p class="experiment-label">Experiment 4</p>

混ぜて学習する前に計算できる量が、交換レートと同じ順位を付けられるかを Spearman の順位相関 ρ で調べました。正の ρ は価値の順位と一致することを意味します。

| 予測に使った量 | 設定 | シード | ρ |
|---|---|---|---|
| 較正なし e<sub>mis</sub>（静的） | GoEmotions、9 プール | 0, 1 | 0.33, 0.30 |
| 較正なし β<sub>KL</sub>（静的） | GoEmotions、9 プール | 0, 1 | 0.88, 0.80 |
| 勾配のコサイン | WRIME、7 プール × 3 n | 0 | −0.61 |
| 勾配の内積 | WRIME、7 プール × 3 n | 0 | −0.89 |
| 勾配のコサイン | WRIME、7 プール × 3 n | 1, 2 | −0.32 |
| 勾配の内積 | WRIME、7 プール × 3 n | 1, 2 | −0.89 |
| 較正した勾配のコサイン | WRIME、7 プール × 3 n | 1, 2 | +0.20 |
| 較正した勾配の内積 | WRIME、7 プール × 3 n | 1, 2 | −0.58 |
| 学習者とラベルの不一致 D | WRIME、7 プール × 3 n | 1, 2 | 0.69 |

静的な指標のうち β<sub>KL</sub> は向きの違いをある程度追えましたが、学習者の状態に依存しないので、実験 1 のような n による符号の反転は原理的に追えません。e<sub>mis</sub> は、確信度の低い permuted 方向を小さな誤りと数えてしまい、最も害の大きいプールを見逃しました。

1 次の勾配の向きは、逆向きの手がかりになりました。開発データの勾配と補助データの勾配のコサインは、21 通りの組み合わせすべてで 0.37〜0.56 と正で、1 次近似ではどのプールもリスクを下げるはずでした。ところが内積が大きいプールほど害が大きくなりました。較正した目的関数の勾配を使うとコサインの相関は +0.20 に上がりますが、シードと n によって −0.89 から +0.82 までばらつきました。不一致 D も、uniform 方向は D が小さいのに後半の害が最大、という同じ失敗が 2 シードで出ました。

一方、**実際に補助データだけで数ステップ更新してみる**と、順位はすぐに現れました。

<figure>
  <img src="/column-images/ssrn-learner-state-data-value/trajectory-1600.webp" alt="Update-trajectory probe" />
  <figcaption><strong>Figure 8.</strong> WRIME の n = 16k の学生から補助データだけで更新したときの、テスト交差エントロピーの変化 −ΔCE(t) と交換レートの順位相関。本文に書かれた値を示しています。</figcaption>
</figure>

順位相関は 1 ステップ後に 0.63、2 ステップ後に 0.90、5 ステップ後に 0.93 で、3 エポック（423 ステップ）の終わりまで 0.88〜0.94 にとどまりました。害のあるプールが、最初はリスクを下げて後から上げる、というパターンは 19 セルのいずれにも見られませんでした。ただし、収束した学生から学習を再開すると、学生がすでに見た実データでも最初の 1 ステップでリスクが上がるため、この手順では「最初のステップの効果」は観測できません。また、この試験はテストデータを使っているので、まだデータ選択の手順にはなっていません。

## 実験 5：評価指標を変えると符号は変わるか

<p class="experiment-label">Experiment 5</p>

実験 3 の 2×2 のプールについて、後半段階での Brier スコアと macro-F1 の変化を見ました。

| コーパス | プール | ΔBrier ↓ | Δmacro-F1 ↑ |
|---|---|---|---|
| GoEmotions | 生成 / teacher | −0.0016 | +0.020 |
| GoEmotions | 生成 / permuted | +0.0029 | +0.017 |
| GoEmotions | 実 / teacher | −0.0049 | +0.026 |
| GoEmotions | 実 / permuted | −0.0043 | +0.032 |
| WRIME | 生成 / teacher | −0.0030 | +0.021 |
| WRIME | 生成 / permuted | +0.0041 | +0.019 |
| WRIME | 実 / teacher | −0.0061 | +0.014 |
| WRIME | 実 / permuted | −0.0058 | +0.008 |

GoEmotions の permuted ラベルの実テキストは、交差エントロピーでは交換レート −0.29 と負でしたが、Brier スコアは 0.0043 下がりました。残りの 7 プールでは交差エントロピーと Brier スコアの符号は一致しています。macro-F1 は 8 プールすべてで改善し、交差エントロピーでも Brier スコアでも害になった permuted ラベルの生成テキストも含まれます。予測クラスを良くするデータが、人間の判断分布への確率的な当てはまりを悪くすることがある、ということです。

## わかったこと・わかっていないこと

この研究でわかったのは次の点です。

- 同じ生成データが、実データの少ない学習者には役立ち、多い学習者には害になった。ゼロ点は学生モデルによって変わった。
- エントロピーを固定しても、ソフトラベルの向きで価値が変わった。害を消したのは教師方向だけで、同じ実データで学習した教師でも効果が残ったので、蒸留だけでは説明できない。
- 間違った向きのラベルは、実テキストより生成テキストで損失が大きかった（WRIME でははっきり、GoEmotions では弱く）。
- 静的な指標や 1 次の勾配では害の順位を当てられず、実際の数ステップの更新では当てられた。価値の符号は評価指標によって変わることがあった。

論文は、学習者の状態に依存する理由として「補助データの価値は、いまの学習者がまだ捉えていない情報をどれだけ足すかで決まる」という仮説を出しています。ただしテキストの情報量は直接測っておらず、仮説の段階です。実テキストが間違ったラベルでも役立った理由（原因や対象、文脈などの手がかりを含むため）も、測定していない仮説として書かれています。

限界もあります。対象は 2 つの感情コーパスだけで、ニューラル学習一般に成り立つとは示していません。コーパスごとの主な学生モデルは 1 つで、生成器の数も少数です。permuted 方向は argmax を保っており、摂動の強さはコーパス間ではそろえていません。n が大きいと交換レートは粗く（GoEmotions では交差エントロピー 0.001 の差が f の 0.06〜0.08 に相当）、主張は符号と順位に基づいています。補助プールの大きさ m は変えていません。目標分布は少人数のアノテータから推定したものです。GoEmotions の向きの介入は全件の教師と 2 シードで、勾配の試験は開発データ、交換レートはテストデータを使っています。

今後は、補助プールの大きさを変えること、摂動の強さをそろえてコーパスを比べること、害の始まりにおける曲率の効果とミニバッチのノイズを切り分けることに取り組みます。生成テキストと実テキストが感情の推定にどれだけ情報を持つかを測り、テキストと人間の判断分布の結びつきを再現する生成器をつくること、感情認識以外のタスクで状態依存性を確かめることも計画しています。
